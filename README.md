# ray-tracing
I spent a LOT of time learning from the textbook. Most of the time was spent understanding the core concepts and code, and the rest was spent copying down the code. For me, the biggest challenge was navigating difficult c++ functions, as I'm currently taking a c++ introductory course, so I'm not very experienced with it. I had to constantly search up functions to understand how they worked, and then come back and learn why we need it for ray tracing. I really enjoyed learning the process, especially with concepts I'd already heard before like anti-aliasing and rendering that I was able to actually wrap my head around. I think the hardest part conceptually was the vector math in the beginning, but after that it was pretty simple. My favorite part was near the end where I was able to mess around with aperture and defocus blur (depth of field for photographers). After working through the headache of understanding refraction with the hollow glass spheres, I was really excited to finally work with something fun. All in all, I had a great time and I look forward to continuing the series.
